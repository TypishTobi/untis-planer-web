Zugang

Diese Seite hat keine eigenen Daten. Sie liest deinen privaten Datenbestand direkt bei GitHub – dafür braucht sie ein Token, das nur in diesem Browser gespeichert wird und nirgendwo sonst hingeht.

Ausgeschaltet gilt es nur, bis du den Tab schließt – sinnvoll auf fremden Geräten.

Wie erstelle ich das Token?
  1. Auf github.com: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → dein Daten-Repository
  3. Permissions → Add permissions → Contents auf Read and write
  4. Ablaufdatum setzen, erzeugen, hier einfügen

Mehr Rechte braucht die Seite nicht. Das Token gilt nur für dieses eine Repository.
